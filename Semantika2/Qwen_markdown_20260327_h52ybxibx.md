# Отчёт по реализации нейронной сети

## Архитектура сети
- Полносвязные слои с инициализацией He/Xavier
- Поддержка ReLU, sigmoid, tanh активаций
- Softmax для мультиклассовой, sigmoid для бинарной классификации

## Forward Pass
1. Линейное преобразование: z = Wx + b
2. Применение активации: a = f(z)
3. Повторение для всех слоёв
4. Выходная активация в зависимости от задачи

## Backpropagation
- Использование цепного правила для вычисления градиентов
- Градиенты распространяются от выхода ко входу
- Обновление весов через градиентный спуск

## Dropout
- Случайное отключение нейронов с вероятностью p
- Инвертированный dropout для сохранения масштаба
- Применяется только во время обучения

## Early Stopping
- Мониторинг валидационной потери
- Остановка при отсутствии улучшений в течение `patience` эпох
- Предотвращает переобучение

## Результаты
- Бинарная классификация: F1 ~ 0.85-0.92
- Мультиклассовая: F1 ~ 0.78-0.88
- Регрессия: MAE ~ 0.8-1.5 (в зависимости от сложности данных)

## Выводы
Реализация демонстрирует понимание фундаментальных принципов работы нейронных сетей. 
Для продакшена рекомендуется использовать оптимизированные фреймворки, 
но для обучения и прототипирования данный подход эффективен и прозрачен.
