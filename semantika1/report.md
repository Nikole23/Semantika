# Отчет по заданию: Анализ синтаксических зависимостей подлежащего и сказуемого
## 1. Подход к решению задачи
- **natasha** - библиотека для обработки русского естественного языка, включающая:
  - `Segmenter` - для разделения текста на предложения и токены
  - `NewsEmbedding` - векторные представления слов для новостных текстов
  - `NewsMorphTagger` - для морфологической разметки
  - `NewsSyntaxParser` - для синтаксического разбора
  - `MorphVocab` - морфологический словарь для лемматизации
- **pandas** - для работы с данными и SQL-запросами
- **sqlite3** - для подключения к базе данных
- **collections.Counter** - для подсчета частот пар
- **matplotlib.pyplot** - для визуализации результатов

## 2. Алгоритм решения
- Шаг 1: Загрузка данных
- Шаг 2: Синтаксический разбор
- Шаг 3: Лемматизация
- Шаг 4: Подсчет частот
- Шаг 5: Визуализация и анализ
